# 码课镜 CodeScope · 编程教学视频结构化讲义生成平台

> **看视频，得讲义——编程课视频一键生成带时间锚点的结构化讲义**

软件工程课程项目 · 4 人小组 · 交付截止 **2026-12-11**
（项目名暂定，组会确认后统一；slogan 与命名见 `分工方案_选题微调与任务分解.md` 第一节）

## 一、它解决什么问题

技术教学视频（B 站 / 慕课 / 内部录播）通常只有一整条时间轴，没有配套讲义：

| 学习者的痛点 | 现状 | 本平台的做法 |
| --- | --- | --- |
| 找不到某个知识点在哪一分钟 | 拖进度条反复回看 | 自动生成**章节大纲 + 知识点索引**，点击直达时间戳 |
| 屏幕上的代码认不出、抄不全 | 纯语音转写拿不到代码，OCR 出来又可能有误 | **代码块结构化提取**，标注识别置信度与来源 |
| 不知道这个知识点的来龙去脉 | 零散笔记与视频割裂 | **知识点—时间戳—笔记**三者双向联动 |
| 看完不知道自己哪里没懂 | 没有重点提示 | **易错点挖掘**：从讲师强调与纠错中提炼复习清单 |

**核心差异化：可信提取。** 不止是把视频变成文字——每条结论都能溯源到原片原话，系统还能发现教程自身的前后矛盾与版本演化。

## 二、它长什么样

```
本地教学视频
   │
   ├─ ① 音频通道：ASR 转写 → 带时间轴的字幕
   ├─ ② 画面通道：关键帧抽取 → OCR 识别代码 / PPT 文字   ← 双通道策略模式
   │
   ▼
结构化解析（LLM）→ 章节 / 知识点 / 代码块 / 时间戳
   │
   ├─ 证据链：每条结论携带 时间戳 + 原话 + 来源帧 + 通道标注
   ├─ 一致性校验：检测教程前后矛盾与代码版本演化
   ├─ 不确定性分级：明述 / 推断 / 低置信
   │
   ▼
前端学习工作台  ⇄  知识图谱视图
   │
   └─ 导出：Markdown 讲义（带时间锚点）· 分享链接 · 预留开放接口
```

## 三、技术栈

| 层 | 选型 |
| --- | --- |
| 前端 | Vue3 + Vite + Element Plus + G6（图谱）+ Video.js |
| 后端 | FastAPI（Python） |
| 解析链路 | yueying 0.2.1（锁版本）+ DeepSeek API |
| 视觉识别 | PaddleOCR / 视觉模型（双通道策略模式） |
| 数据 | MySQL（业务实体）+ Redis（缓存） |
| 交付 | Docker Compose 一键启动 |

## 六、协作方式

- 分支模型：`main` 受保护 → `feature/<name>-<topic>` → PR 合并，**禁止直推 main**
- 提交信息：Conventional Commits（如 `feat(design): 图7 增加讲义修订状态机`）
- **变更记录逐版本、逐人署名，禁止合注**（见 `CHANGELOG.md`）
- 图源文件（draw.io / PlantUML）入库，SVG 为导出物
- 完整规约见 [CONTRIBUTING.md](CONTRIBUTING.md)
