### 墨刀里的交互

页面之间的跳转都是墨刀原生的「单击 → 跳转页面」交互，可以在墨刀编辑器里直接修改。已在预览中实测：

| 动线 | 操作 | 结果 |
| --- | --- | --- |
| 页 4 动线 1 | 点左栏大纲「15:10 解构陷阱」或刻度尺上的章节色块 | 04b：播放头、画面、字幕跳到 15:10 |
| 页 4 动线 2 | 点右栏「总结 / 要点 / UML / 代码块」 | 04 / 04c / 04d / 04f 面板切换 |
| 页 4 动线 3 | 在 UML 面板点节点「computed 与 watch」 | 04e：跳到 21:30 并提示「已跳到…」 |
| 证据链 | 点刻度尺 3 号圆标或「看证据链」 | 05：右侧证据链抽屉；点「关闭」或抽屉外回到 04 |
| UML 图种 | 页 6 点「用例 / 类 / 时序 / 流程」 | 06 / 06b / 06c / 06d |
| 全局 | 顶栏「视析 / 视频库 / 批量上传 / 知识检索 / 批次后台 / 设置」 | 各自页面；封面目录可进入全部 12 页 |

**搭建方式**：墨刀「HTML 转墨刀」会把页面内的 `#` 链接识别为页面跳转并逐个生成页面。`source/flow.mjs` 生成一个单文件 HTML：每屏一张导出图（引用墨刀图床上的同一批图），上面叠透明 `#` 热区；导入并「转为可编辑元素」后即得到全部页面和跳转。改热区时改 `flow.mjs` 里的坐标表重新导入即可。

## 重新导出

`source/export-2x.mjs` 用本机 Chrome 无头模式按 2 倍像素密度截整页，不依赖第三方包。运行它需要设计画布的运行时文件（画布的 `artifact-type/dc-runtime.js`，放到页面目录下命名为 `support.js`），该文件属于画布工具，不入库。

```bash
node docs/prototype/source/export-2x.mjs <页面目录的上一级> <输出目录> p04-workbench@2x:Workbench.dc.html:1000
```

页 05 是工作台打开证据抽屉的状态，导出时用工作台副本把初始状态设为证据抽屉打开。
