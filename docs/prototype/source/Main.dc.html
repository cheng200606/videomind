把每条视频画成一把尺子

知识点是尺子上的刻度，讲错的地方是一段红色斜线。学习者不用看完视频，扫一眼尺子就知道哪里讲了什么、哪里讲错了、哪里最该复习。

实心 / 空心 / 虚线刻度编号的笔画就是置信度：明述、推断、低置信。不靠颜色也分得清。
红色只有一种意思易错、讲错、当前位置。整套界面除此之外只用黑白灰。
大数字说真话每页最大的那个数字都是用户最想知道的量：几条完成、几条命中、占多少空间。
没有卡片用 2px 黑线分区，12 栏网格对齐；直角，无投影，无圆角。字体 Inter Tight 配思源黑体。
