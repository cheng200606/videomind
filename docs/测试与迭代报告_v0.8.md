# VideoMind 视析 v0.8 端到端测试与迭代报告

> 测试日期：2026-11-06 · 版本基线：v0.7.1（develop） · 测试对象：`backend/` + `frontend/` 生产构建
> 说明：所有识别结果仅供参考；本报告不包含任何 API Key、Token 或本机绝对路径。

## 一、结论摘要

本次对 VideoMind 做了一次隔离环境下的端到端全流程测试：离线确定性全链路（mock ASR + 无 Key 规则兜底）覆盖上传、四阶段解析、SSE、标签、检索、笔记、讲义状态机、导出、设置、删除与异常边界；另用真实 DeepSeek 跑通一次真实结构化；用本机 Edge 无头 CDP 覆盖 7 个视图、37 项 UI 断言、42 个响应式组合。测试过程中发现并修复了 22 个问题（P0 6 个、P1 9 个、P2 7 个），其中 3 个是迭代过程中由 E2E 新发现的回归/细节缺陷。

**最终结果**

| 维度 | 结果 |
|---|---|
| 后端 pytest | **73 passed / 73**（基线 69，新增 4 个回归用例；11.69s） |
| 前端 vitest | **23 passed / 23**（基线 18，新增 5 个用例；1.55s） |
| 生产构建 | `vue-tsc --noEmit && vite build` 通过 |

**评分（1–5，基于本次测试口径）**

| 维度 | 迭代前 | 迭代后 | 主要依据 |
|---|---:|---:|---|

| 界面/视觉/交互/响应式 | 4.0 | **4.5** | 布局与主色统一、移动端导航与卡片化补齐；大编辑器空态、深色/打印、真机 WCAG 仍可继续 |

**结论**：核心使用场景已可稳定演示——批量导入 → 四阶段解析 → 批次进度 → 知识工作台取证 → 标签/检索 → 笔记/讲义 → 批次导出。v0.7 自评中偏乐观的“状态同步、标签作用域、响应式”三块，在本次复测中被证伪并已修复；当前主要剩余风险集中在长视频资源边界、真实 ASR/OCR 路径和真机/容器环境，而非主流程功能。

## 二、测试环境与方法

### 2.1 隔离策略

现有 8000/5173 运行实例及其 `output/e2e-v0.7/` 数据未触碰。本次使用独立端口与数据目录：

| profile | 端口 | 数据目录 | 引擎 | 用途 |
|---|---|---|---|---|
| offline | 8100 | `output/e2e-v0.8/data/final` | `ASR_ENGINE=mock`、`OCR_ENGINE=none`、Key 空 | API/UI/响应式/性能主回归 |
| real-llm | 8102 | `output/e2e-v0.8/data/real-llm` | mock ASR + 真实 DeepSeek env Key | 真实结构化验证 |

- 前端先 `npm run build`，由 8100 同源服务 `frontend/dist`，验证生产构建与按需样式，而不是 dev 热更新环境。
- 每个 profile 启动前删除 `settings.json` / `model_settings.json`，避免持久化设置覆盖环境变量。
- 素材：`output/e2e-v0.7/media/clip_2min.mp4` 复制为 `lecture_a/b.mp4` 与 `unknown.mp4`；fixture 目录复制 `lecture_transcript.json` 为 `lecture_a/b.json`，保证 mock 可确定性命中且视频真实可播放。
- 真实 Key 只从本机已保存模型配置读入子进程环境变量（`DEEPSEEK_API_KEY` 等），不写文件、不打印；报告生成后做 API Key/Bearer Token 模式扫描。真实调用共 2 次（连接测试 + 一次结构化）。

### 2.2 工具链

- 后端：pytest 9.2 + FastAPI TestClient（单元/集成）、httpx（真实 HTTP）。
- 前端：vitest 5.1 + jsdom（store/标签/错误格式化）、vue-tsc（类型检查）。
- 浏览器：本机 Edge 无头 + CDP（Node 24 内置 WebSocket），未下载新浏览器；截图与指标落 `output/e2e-v0.8/`。

## 五、优化方案与优先级

### P0（正确性与演示稳定性）— 已完成

1. 标签检索作用域：视频级标签命中该视频全部条目，条目级只命中自身，与其他过滤条件 AND。
2. 单条视频终态：新增 `video_events=1` 开关，事件 `stage=batch`、`video_id` 非空、`status=succeeded|partial|failed`；前端终态判定必须 `video_id=null`。
3. SSE 断线兜底：重连 hooks + 4s 快照轮询 + 连接中断横幅 + 重新连接按钮。
4. 历史回放：ProgressBus 每批 256 条、全局 64 批 LRU、seq 单调；刷新/重连回放；重跑 reset、删除 forget。
5. 终态配色：成功/部分成功补齐 success/warning。
6. 上传离开保护：结果页跳转不被“未保存”拦截。

**验收**：后端 73/73、API 49/49、UI 37/37；SSE 历史回放与单条终态均有自动化断言。

### P1（体验一致性）— 已完成

1. 设置清 Key 仅清 Key，不持久化未保存表单。
2. 标签操作失败可见、防连点、人工标签“移除”语义。
