## 三、协作机制（过程分 20 分的护城河）

1. **周会**：每周日晚 30 分钟，固定三议程——对进度（对照本周验收物）、对风险、定下周任务
2. **纪要轮值**：A → B → C → 组长 循环，当周纪要人**当场成稿**，组长统一归档——既是课程「讨论记录」素材，也是四人贡献度证据
3. **Git 约定**：源文件（md / drawio / puml）一律入库，SVG 为导出物；**每人只 commit 自己负责的章节/图**——这是变更记录"逐人署名"的证据链
4. **变更记录**：列 = 版本 / 日期 / 章节 / 作者 / 修改摘要；每人在自己章节下**自记条目**，组长每周审计一次
5. **飞书任务板**：按周分列，每张卡必有「验收物 + 负责人 + 截止日」，没有验收物的任务不许上板
6. **掉链子预案**：任务超期 48h 在周会重排；W4 与 W6 两个硬节点前各留 1 天缓冲；不加双人备份，靠周会早暴露

完整规约见 `CONTRIBUTING.md`。
