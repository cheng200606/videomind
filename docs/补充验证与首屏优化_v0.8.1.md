## 三、长视频内存边界（O-01）

### 3.1 复现

首轮用 yueying small + RapidOCR 直接跑 28 分钟，34 秒后转写阶段失败：

```
numpy._core._exceptions._ArrayMemoryError:
Unable to allocate 513. MiB for an array with shape (1, 168003, 400) and data type float64
```

调用栈定位在 faster-whisper 的 `FeatureExtractor.stft` → `np.fft.rfft`：整段 28 分钟音频一次性生成 STFT。采样到进程树峰值：工作集 937.6 MB、私有提交 3520.7 MB。这与 v0.7 记录的 numpy 分配失败一致。

### 3.2 修复

1. **yueying 子进程的 VAD 分段上限**：新增 `backend/app/engines/yueying_compat.py`，在 yueying 启动前把 `get_speech_timestamps` 的 `max_speech_duration_s` 从 `inf` 限制为 30 秒；yueying 仍负责抽帧与字幕，但特征提取按 30 秒 chunk 进行。
2. **RapidOCR 线程上限**：`RapidOcr` 初始化时固定 `intra_op_num_threads=2`、`inter_op_num_threads=1`。隔离测量中默认线程配置的 OCR 会话明显更占内存；2 线程配置在 5 张帧上的识别耗时 5.4 秒，作为长视频内存与吞吐的折中。
3. **子进程编码**：`yueying` 输出按 UTF-8 解码（`errors="replace"`），避免 Windows 默认 GBK 在 reader 线程抛 `UnicodeDecodeError`。

### 3.3 结果

连续上传两个 28:00 视频（同一后端进程、不同批次）：

| 指标 | 第 1 次 | 第 2 次 |
|---|---|---|
| 批次状态 | succeeded | succeeded |
| 耗时 | 277.1 s | 281.1 s |
| 转写段数 | 206 | 206 |
| 条目/证据 | 17 / 17 | 17 / 17 |
| 关键帧 | 28 | 累计 56（第二次新增 28） |
| 导出 | 200，Markdown | 200，Markdown |
| 阶段 | 四阶段 done | 四阶段 done |

两次合计采样峰值：工作集 **2001.4 MB**、私有提交 **5609.7 MB**；无 MemoryError、无进程崩溃。失败轮次的 3520.7 MB 私有峰值被成功轮次的整体峰值覆盖，说明关键不是“总内存低于某个绝对值”，而是避免单次超大连续分配。

**仍未覆盖**：三次以上连续长视频、低于 16 GB 内存的机器、真实 27:56 课程视频与并发批次。建议 v0.9 把 ASR/OCR 放入独立 worker 或做流式分段，彻底隔离提交峰值。

## 十一、剩余风险与未覆盖

1. **Docker 构建网络**：仓库 Dockerfile 直连 Debian/PyPI 时只有十几 KB/s；本次用阿里云镜像的临时 Dockerfile 完成测试构建。CI 或新机器需要镜像源/代理；compose 只为 mysql 配了 healthcheck，backend/frontend 无 healthcheck。
2. **安装包签名与更新**：安装包未配置代码签名；自动更新的下载/安装链路未覆盖，只验证了 `latest.yml` 版本为 0.8.1。
3. **WSL 数据**：原 Ubuntu `ext4.vhdx` 丢失，已重新导入为 root 用户；重启后 WSL/Docker 均恢复，但原发行版数据不可恢复，用户级配置需重新建立。
4. **长视频峰值**：两次连续 28 分钟成功，但私有提交峰值约 5.6 GB；3 次以上连续、低于 16 GB 内存或同时跑 Docker 时仍可能触发提交不足。建议 v0.9 做 worker 隔离/流式 ASR。
5. **真实设备**：无真机与读屏人工测试；axe 覆盖 WCAG 2.0/2.1 A+AA 的自动规则，不等同于完整 WCAG 结论。
6. **LLM**：本轮真实引擎测试使用无 Key 规则兜底，未评价 DeepSeek 结构化质量；真实 Key 调用仍按 v0.8 报告的 2 次记录。
7. **OCR 线程**：2 线程降低内存占用，但可能降低批量 OCR 吞吐；当前只对长视频场景做了取舍验证。
8. **未覆盖**：真实 27:56 课程视频、并发批次、Docker Hub 原始网络构建耗时、Windows 容器、代码签名、自动更新下载/安装。
