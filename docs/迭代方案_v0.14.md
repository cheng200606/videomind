## 二、迭代项明细

### P0-1 解析覆盖提示贯通到导出物与快照

- **目标**：工作台横幅里的诚实声明必须随文稿带走，外部插件只读快照同源可查。
- **改动**：`app/export.py` 新增 `coverage_notices(session, video, items)` 作为单一口径（视频终态 PARTIAL/FAILED + 摘要产物 `payload.notice`）；批次头汇总非「成功」视频数，各视频段输出「解析覆盖提示」区块；`app/routers/delivery.py::structured` 每条视频新增 `coverage_notice`（无提示为空串）；导出页 API 说明同步。
- **验收**：有 notice 时导出含提示与「请回看原片核对」；部分成功时批次头汇总 + 状态/notice 双提示；干净批次不产生空提示块；快照字段与文稿同源；既有 92 例不回归。

### P0-2 移除 API 绝对路径字段

- **目标**：面向 UI 的响应不再回显本机绝对路径。
- **改动**：`parse.py::_video_view` 删 `path`；`types.ts` 的 `VideoState` 改 `file_name`/`media_url` 必填；`BatchProgressView.vue` / `WorkbenchView.vue` 共 5 处历史 fallback 收敛；两处后端测试改用 `get_settings().media_root` + `{batch_id}_{filename}`；前端 fixture 同步。
- **验收**：新增断言两端点响应无 `path`、无运行时目录片段；`vue-tsc` + `build` 通过；文件落盘/级联删除类测试不回归。

### P0-3 OCR 帧去重复用抽帧口径

- **目标**：消除对已排除依赖的隐式依赖，让桌面发行版与源码行为一致且降级可见。
- **改动**：`frames.py` 公开 `SIMILAR_THRESHOLD` / `abs_diff` 并新增 `file_thumbnail`（Pillow + numpy，桌面包内已有）；`ocr.py::dedupe_frames` 改用同一套 16×16 灰度均值差，移除 imagehash，读图失败保留该帧并记 warning；`requirements.txt` 删 imagehash 行、Pillow 注释校准；spec 注释更新；`.env.example` 修正「用 openai SDK」的错误表述并补默认 SQLite 说明。
- **验收**：新增 3 例（模拟桌面无 imagehash 时去重仍生效、去重口径与抽帧一致、坏帧保留 + warning）；全仓无 `_abs_diff`/`_SIMILAR_THRESHOLD` 残留引用。

### P1-1 / P1-2 / P2

- **P1-1**：README 技术栈、进度、桌面下载与更新说明按 v0.13 实况重写；保留逐人署名与合规声明，不出现红线禁用的无据表述。

## 五、关键决策与说明

1. **P0-2 中途发现 5 处前端 `video.path` 消费**：`vue-tsc` 在移除类型字段后报错，核对确认全是 `file_name || path.split(...)` 一类历史 fallback，而后端始终返回 `file_name`/`media_url`。决策是**不恢复 `path` 字段**，而是把消费方收敛到必填字段——既达成脱敏目标，也消除了「字段可能为空」的隐含假设；否则本项会退化为只改后端、前端继续依赖路径。
2. **P0-3 为中途纳入**：只读扫描发现该静默降级，性质与本轮「诚实性收口」一致且改动可控，故扩入 P0。决策是**复用 `frames.py` 已有的 numpy 均值差**而非引入新实现或新依赖，使 AGENTS.md 中「抽帧去重用 frames.py」的表述名副其实；保留 spec 的 imagehash/scipy excludes 作为防御，不改 OCR 引擎对外契约。
3. **`coverage_notice` 未同步 `types.ts`**：`/structured` 是外部插件只读端点，前端仅有说明文案、不消费该响应；新增可选字段属向后兼容，不触发「后端 schema 变更同步 types.ts」的红线，已在 AGENTS.md 记录口径。
4. **不代组员署名**：CHANGELOG v0.8/v0.8.1 缺口按课程模板「逐人署名、严禁合注」红线与 v0.11 报告结论保持不变。
5. **未做端到端发布验证**：本版不含 Release，阶段 2 增量更新应用端与真实 Key 长视频回归仍无法验证，维持为下一发布周期候选。
