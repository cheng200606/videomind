## 一、机器可判定的四项（必须 exit 0）

在仓库根目录执行（`--root` 默认已指向 `docs/delivery`，无需再传）：

```bash
python tools/check_doc_refs.py
python tools/check_figure_refs.py
python tools/check_doc_banned.py
python tools/check_doc_numbers.py
```

| # | 脚本 | 判定口径 | 实测 | 结论 |
|---|---|---|---|---|
| 1 | `tools/check_doc_refs.py` | 正文所有 `文件:行号` 引用必须解析到真实文件，且行号不越界。basename 会按 `backend`、`backend/app`、`frontend`、`frontend/src`、`desktop` 前缀试探。 | 待填 | ☐ |
| 2 | `tools/check_figure_refs.py` | 图注必须带真实存在的 `docs/figures/svg/*.svg`，或显式标「待补」；正文引用的图号必须能对应到同号图注，否则判悬空。`排版规范.md` 中的示例图注自动跳过。 | 待填 | ☐ |
| 3 | `tools/check_doc_banned.py` | 禁用词「首次 / 唯一 / 100% 准确 / 完全自动」命中数为 0。白名单只放行「唯一出口 / 唯一权威 / 唯一路径」这类**单一口径**表述，宣称产品能力唯一性的一律命中；历史记录类文件（CHANGELOG、HANDOFF-、测试与迭代报告_、补充验证与首屏优化_、迭代方案_）跳过。 | 待填 | ☐ |
| 4 | `tools/check_doc_numbers.py` | 表数、枚举数、用例数与代码/实跑值同源，偏差为 0。用例数须带采集时刻（日期 + commit 短号），只写数字不写时刻的表判过期。 | 待填 | ☐ |

> 退出码约定：全绿为 `0`，存在缺陷为 `1`。**任何一项非 0 都不得提交**。反向自检法：临时把某条真实引用的行号改成一个不存在的大数、或把某个表数改错，确认脚本能报出来，再从备份还原——脚本报不出来的「全绿」没有意义。（**不要在正文里留下这条测试引用**，它会被当成真引用校出来。）
