## 4. 写文档的四条硬规矩

1. **图必须矢量化且成对入库**：源文件（`.drawio` / `.puml` / 生成脚本）与 `.svg` 都要进版本库；结构图禁止用 PNG 代替。界面的墨刀导出位图与结构示意 SVG 在正文里要分清。
2. **每条结论可溯源**：涉及实现与行为的描述，指到 `backend/app/` 或 `frontend/src/` 的具体文件与行为；涉及数据的描述，指到 [数据字典.md](数据字典.md) 的字段。
3. **诚实边界照抄不美化**：AI 产出标「识别结果仅供参考」；截断、跳过、通道不可用、兜底降级都要写成显式声明，不得静默。
4. **变更记录逐版本逐人署名**：不设专人代写，禁合注；格式与例外见 [../CONTRIBUTING.md](../CONTRIBUTING.md)。

**禁用无据表述**：「首次」「唯一」「100% 准确」「完全自动」，以及任何无法用代码或实测数据支撑的绝对化说法。确有限定语语境（如「本文唯一权威口径」这类指代性用法）时，在质量门脚本的白名单里登记，不要为通过扫描而改写原意。
