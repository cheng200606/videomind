## 二、代码的定位

交付形式是**讲 PPT，不现场演示系统** → 系统的"现场说服力"归零，代码只剩**加分项**一种价值。

**因此编码目标不是"功能完整"，而是"能产出可信证据"：**

| 交付 | 数量 | 用途 |
| --- | --- | --- |
| 真实运行截图 | 5 张（上传页 / 解析进度 / 播放器+大纲 / 代码块 / 笔记导出） | 贴 PPT |
| 录屏 | 1 段 60 秒 | 二维码放 PPT 末页，扫码看 |
| 可复现的样例数据 | 2 条预解析视频（1 条中文讲课、1 条满屏代码） | 截图与录屏的素材源 |

**只做一条垂直切片**：选本地视频 → 调 yueying 出字幕与关键帧 → DeepSeek 结构化 → 存 JSON → 前端读 JSON 渲染大纲/代码块/笔记 → 导出 Markdown。

> 关键判断：**一条能截图的窄链路，价值高于一个跑不动的完整系统。** 编码压到 W5 的 3 天内完成，剩余时间还给文档与原型。

| # | 页面 | 关键点 | 对应评分点 |
